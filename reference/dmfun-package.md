# dmfun: Miscellaneous Functions Primarily for R Package Development

Hodgepodge collection of functions, mostly for helping with R package
development. Generally, the functions are meant to be used interactively
as you're developing a package.

## Details

The functions herein have no necessary relation beyond provenance.
